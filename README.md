# GrandYea

GrandYea — лёгкий графический редактор локальных XML-телефонных книг для
телефонов Grandstream и Yealink. Приложение рассчитано на одного оператора и
синхронно обновляет оба файла.

## Возможности

- Grandstream используется как основная телефонная книга;
- добавление, редактирование и удаление контактов;
- поля: фамилия или название, имя, отчество и номер телефона;
- отображение контактов всех групп Grandstream;
- автоматическое добавление новых контактов в группу `Work`;
- поиск и сортировка таблицы;
- проверка уникальности номера и разрешение только цифр;
- генерация Yealink XML из актуального содержимого Grandstream;
- защита от перезаписи файлов, изменившихся после загрузки;
- безопасная запись через временные файлы без постоянных `.bak`;
- локальные пути к книгам в настройках;
- один переносимый EXE без установленного Python.

## Формирование имени Yealink

| Заполненные поля | Результат |
| --- | --- |
| Фамилия | `Фамилия` |
| Фамилия и имя | `Фамилия И.` |
| Фамилия, имя и отчество | `Фамилия И.О.` |

XML Grandstream не имеет отдельного стандартного поля отчества, поэтому оно
хранится в `FirstName` вместе с именем в виде `Имя Отчество`.

## Использование

1. Скачайте `GrandYea.exe` из раздела **Releases**.
2. Запустите приложение и нажмите **Настройки**.
3. Укажите локальные пути к XML-файлам Grandstream и Yealink.
4. Измените телефонную книгу.
5. Нажмите **Сохранить** — оба XML-файла будут обновлены.

Настройки сохраняются в `%APPDATA%\GrandYea\settings.ini`, журнал ошибок — в
`%APPDATA%\GrandYea\grandyea.log`.

В каталоге [`examples`](examples) находятся две согласованные телефонные книги
с полностью вымышленными контактами. Их можно использовать для знакомства с
программой. Реальные локальные книги `grandstream.xml` и `yealink.xml` в корне
проекта исключены из Git, чтобы случайно не опубликовать персональные данные.

## Совместимость

Релиз собирается для Windows x64 с Python 3.8 и PyInstaller 4.10. Основная
целевая система — Windows Server 2008 R2 SP1 x64. Для запуска Python 3.8 на ней
должны присутствовать системные компоненты `KB2533623` и Universal C Runtime
(`KB2999226`). Рекомендуется проверить готовый EXE непосредственно на целевом
сервере перед эксплуатацией.

## Запуск из исходного кода

Требуется Python 3.8 с Tkinter. Сторонние библиотеки для самого приложения не
нужны.

```powershell
python grandyea.py
```

## Тесты

```powershell
python -m unittest -v
```

Тесты работают только с вымышленными XML из каталога `examples`.

## Сборка EXE

```powershell
python -m pip install -r requirements-build.txt
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Python python
```

Результат: `dist\GrandYea.exe`.

## Автоматические релизы

Workflow [`.github/workflows/release.yml`](.github/workflows/release.yml):

1. устанавливает Python 3.8 x64;
2. запускает тесты;
3. собирает один `GrandYea.exe`;
4. сохраняет EXE как artifact;
5. при отправке тега `v*` создаёт GitHub Release и прикладывает EXE.

Также к релизу прикладывается файл `GrandYea.exe.sha256` для проверки загрузки.
