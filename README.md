# GrandYea

Редактор XML-телефонных книг для телефонов Grandstream и Yealink.

## Что делает

- загружает телефонную книгу Grandstream;
- позволяет добавлять, изменять и удалять контакты;
- редактирует фамилию, имя, отчество и номер телефона;
- показывает контакты из всех групп Grandstream;
- добавляет новые контакты в группу `Work`;
- проверяет уникальность телефонных номеров;
- поддерживает поиск и сортировку;
- при сохранении обновляет книги Grandstream и Yealink одновременно;
- формирует имя Yealink в виде `Фамилия`, `Фамилия И.` или `Фамилия И.О.`.

Пути к XML-файлам задаются в настройках приложения.
